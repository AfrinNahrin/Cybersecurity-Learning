# 🔐 File Hash Checker (MD5 & SHA256)

A professional Python-based cybersecurity tool that generates and verifies MD5 and SHA256 hashes for files.

---

## 📌 Features

- Generate MD5 Hash
- Generate SHA256 Hash
- Verify SHA256 Hash
- File Existence Check
- Menu Driven CLI
- Error Handling
- Modular Code Structure
