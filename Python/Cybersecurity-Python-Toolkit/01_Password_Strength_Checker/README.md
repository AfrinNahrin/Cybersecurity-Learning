# 🔐 Password Strength Checker

A professional Python-based Cybersecurity Password Toolkit that analyzes password strength, detects common security weaknesses, generates secure passwords, and exports reports in multiple formats.

---

## ✨ Features

- ✅ Password Strength Analysis
- ✅ Entropy Calculation
- ✅ Password Score (0-5)
- ✅ Risk Level Detection
- ✅ Password Statistics
- ✅ Detect Common Passwords
- ✅ Detect Sequential Patterns
- ✅ Detect Repeated Characters
- ✅ Password History
- ✅ Secure Password Generator
- ✅ Export JSON Report
- ✅ Export CSV Report
- ✅ Export TXT Report
- ✅ Automatic Report Opening
- ✅ Colorful Terminal Output

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/AfrinNahrin/Cybersecurity-Learning/tree/406d3c007b8257cc7c09bf593c51f8fb95c6ffc1/Python/Cybersecurity-Python-Toolkit.git
```

Go to project folder

```bash
cd 01_Password_Strength_Checker
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
